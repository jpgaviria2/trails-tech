# Contributing to Trails Tech

Trails Tech is a community-built learning platform. Contributions should make practical technology easier to understand, safer to use, and easier to verify.

## Ways to contribute

- Correct an error or stale source
- Improve a lesson's clarity or accessibility
- Add an exercise, translation, transcript, or original media file
- Propose a new learning path
- Improve the interface, tests, or documentation

## Lesson standard

Every lesson must include a clear outcome, concise reading, a practical exercise, a discussion question, and at least one authoritative source. State limitations plainly. Do not include confidential information, copied proprietary material, undisclosed promotion, or instructions that remove appropriate human oversight.

## Pull requests

1. Fork the repository and create a focused branch.
2. Make one coherent change.
3. Run `npm test`.
4. Explain the learner benefit and list the sources used.
5. Open a pull request and respond to review.

Small corrections are welcome. For a new learning path or structural change, open an issue first so contributors can agree on scope.

## Licence agreement

By submitting a contribution, you agree to license it under the repository's MIT License and confirm that you have the right to do so. Third-party works must be linked or clearly identified with their original licence; do not commit them as if they were MIT-licensed.
