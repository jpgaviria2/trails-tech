# Security Policy

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Report it privately through GitHub's **Security** tab using a private vulnerability report.

Include the affected URL or file, reproduction steps, impact, and any suggested mitigation. Do not access other people's data, send messages, create submissions, or perform denial-of-service testing.

We will acknowledge a complete report as soon as practical and coordinate disclosure after a fix is available.
